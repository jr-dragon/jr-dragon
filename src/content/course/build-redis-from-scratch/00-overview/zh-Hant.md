在這個課程中將會從零開始以 Go 建構一個與 Redis 相容的記憶體內資料庫，目標是為了能夠解釋像 Redis 這樣的軟體是如何打造的、它有什麼特性與限制。

Redis 是一個久經考驗的成熟軟體，因此我們並不會在這個課程中完整實現所有功能，而是著重在常見的特性上並利用這些為你解釋它背後的軟體工程思想、資料結構等電腦科學中常見的底層細節。

## 目標

- 建立一個記憶體內資料庫，支援字串格式的資料
- 閱讀規格，並且構建高效率的 RESP 解析器
- 以 Append Only File 進行資料持久化
- 設計過期資料淘汰演算法

## 如何閱讀

### 程式碼用法及習慣

標準的程式碼顯示方式如下：

```go ./main.go
package main

func main() {
}
```

部份檔名是可以點擊的，它會顯示專案當前的檔案列表，並且可以瀏覽其它檔案：

```go {./main.go}
```
